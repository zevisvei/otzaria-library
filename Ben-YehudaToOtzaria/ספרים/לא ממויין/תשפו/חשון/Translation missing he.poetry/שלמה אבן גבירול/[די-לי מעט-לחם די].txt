שלמה אבן גבירול
<h2 id="די-לימעט-לחםדישלמהאבןגבירול">[די-לי מעט-לחם די] / שלמה אבן גבירול</h2>
<br/>
<p>וקאל איצ ͘ א</p>
<p>— — È — / — — — // — — È — / — — —</p>
<br/>
<blockquote><p>דֵּי-לִי מְעַט-לֶחֶם דָּי / וּבְלוֹי סְחָבוֹת מַדָּי</p></blockquote>
<blockquote><p>מַה-לַּהֲלֹךְ אַחַר גּוּף / יִבַשׁ כְּמוֹ צִיץ-שָׂדָי.</p></blockquote>
